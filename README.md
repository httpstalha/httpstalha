### 🚀 Featured Projects

**🧠 AI Recruitment & Resume Screening**
AI-powered recruitment system that turns manual resume review into a smarter, data-driven process. Extracts structured candidate data via NLP, performs semantic matching against job requirements, and ranks candidates using multi-dimensional scoring (Overall Match, Skills, Experience, Education), surfaced through a recruiter-facing analytics dashboard.
`Python` `NLP` `Semantic Matching` `Resume Parsing` `Dashboard`

**💰 FinFlow — AI-Powered Personal Finance Dashboard**
Full-stack personal finance platform with real-time income/expense tracking, category-wise spending visualization, budget monitoring, and monthly reports. Supports PDF/CSV bank statement upload with automatic transaction extraction & categorization, plus JWT + bcrypt secured authentication.
`Node.js` `Express.js` `JWT` `Chart.js` `REST APIs`

**🩺 Diabetes Prediction System (Med-AI)**
End-to-end clinical AI system predicting Type 2 Diabetes risk from 30 clinical biomarkers (HbA1c, HOMA-IR, fasting glucose, BMI, family history). Random Forest ensemble with a Scikit-Learn preprocessing pipeline, deployed as an interactive Streamlit app with a real-time Plotly risk gauge and patient-specific clinical recommendations.
`Python` `Scikit-Learn` `Streamlit` `Plotly`

**🫘 Kidney Disease Prediction (CNN)**
CNN (TensorFlow/Keras) trained on 12,000+ CT scan images to classify 4 renal conditions — Normal, Cyst, Tumor, Stone. Optimized convolutional layers and augmentation strategy; evaluated using AUC, Precision, and Recall for clinical relevance.
`Python` `TensorFlow` `Keras` `CNN`

**🛣️ Pothole Detection System (RoadGuard AI)**
AI-powered road-infrastructure monitoring platform detecting, classifying, and geolocating potholes in real time from images, video, and webcam feeds using YOLOv8. Multi-factor severity scoring engine (area ratio, aspect ratio, confidence) with a Flask dashboard, interactive GPS heatmap, SQLite-backed detection history, and a unified CLI.
`Python` `YOLOv8` `Flask` `SQLite`

**🚦 Smart Traffic Management System**
Real-time computer vision system for traffic monitoring using YOLOv8 and OpenCV across live webcam and CCTV feeds. Vehicle detection, vehicle counting, lane-wise density monitoring, and smart signal logic that dynamically adjusts timing based on real-time congestion analytics.
`Python` `YOLOv8` `OpenCV`

**🌍 AI Orchestrator Services (KhidmatAI)**
Geospatial service-orchestration platform processing natural-language requests in Roman Urdu, Urdu, and English to coordinate an autonomous multi-agent pipeline — language parsing, date/time extraction, location discovery via Google Places API with OpenStreetMap fallback, transaction finalization, and automated follow-up notifications. FastAPI backend with a Flutter mobile client.
`Python` `FastAPI` `Flutter` `Multi-Agent`

**🎨 AI Image Generator**
AI-driven image generation tool built as part of ongoing work with Hexovate Solutions.
`TypeScript`

**🐞 Bug Solver Agent**
An AI agent designed to analyze and help resolve code issues automatically.
`Python`
